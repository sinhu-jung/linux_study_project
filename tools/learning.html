이해하고, 풀고, 다시 설명하는 학습실

입문 30단계에서 시작해 Linux v6.12 원본 해설로 이어집니다. 모든 수업의 문제와 답지를 순서 제한 없이 볼 수 있습니다.

진도는 이 브라우저에 저장됩니다. 브라우저·파일 위치를 바꾸거나 데이터를 지우기 전 백업하세요. 기존 학습실의 SQLite 진도와는 별도입니다.

하루 45~60분, 개념에서 소스까지

  1. 개념을 읽고 예제의 결과를 먼저 예측하세요. (10분)
  2. 실습을 수행하거나 상태 변화를 손으로 추적하세요. (15분)
  3. 문제를 풀고 정답의 이유와 오답의 이유를 확인하세요. (15분)
  4. 자기 말로 설명을 남기고 복습할 문제를 풀어보세요. (10분)

입문 30단계는 하루 한 수업을 기준으로 삼되, 이해가 안 된 내용은 반복하세요. 이후 Linux 커널 과정에서 같은 주제를 찾아 함수의 정상·실패 경로를 직접 추적합니다.

전체 CS나 Linux의 모든 구현을 이수만으로 숙달했다고 보장하지 않습니다. 문제 점수와 별개로 직접 구현·디버깅·설명하는 능력을 확인하세요. 실습 명령은 자동 실행되지 않으며 Linux/WSL과 별도 도구가 필요할 수 있습니다.
