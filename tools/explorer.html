시작 경로

각 경로는 출발점입니다. 호출 함수와 헤더를 따라가며 범위를 넓혀가세요.

학습 순서

1. 파일의 역할을 한 문장으로 적기
2. 핵심 구조체와 진입 함수 찾기
3. 호출하는 함수와 호출받는 위치 검색하기
4. 잠금·메모리 수명·오류 반환 확인하기
5. Linux 실습 결과와 연결하기
6. 설명할 수 있으면 완료로 표시하기

실습: ./tools/lab.sh read
커널 빌드: ./tools/lab.sh build
QEMU 부팅: ./tools/lab.sh boot

Git 원본을 직접 읽으므로 Mac의 대소문자 파일 충돌 없이 모든 파일에 접근할 수 있습니다. 진도와 메모는 이 컴퓨터에 저장됩니다.
